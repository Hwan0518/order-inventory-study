프로젝트 지침으로 이미 로드된 `AGENTS.md`의 **`/study` 시작 절차**를 실행하라.

- 현재 진행 상태와 실제 코드를 대조한다.
- 사용자에게 지침이나 문서를 요약하지 않는다.
- 이미 끝난 단계를 반복하지 않는다.
- 현재 체크포인트에서 필요한 설명, 고정 질문 하나, 검증 또는 코드 작업을 즉시
  수행한다.
- 사용자 답변이 필요하면 질문 하나만 제시하고 기다린다.
