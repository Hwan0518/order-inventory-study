# Order Inventory Learning

AI 튜터와 함께 재고관리 시스템을 단계별로 구현하는 학습 프로젝트다.

## 학습 시작 또는 재개

저장소 루트에서 Claude Code를 실행한 다음 아래 명령 하나만 입력한다.

```text
/study
```

AI 튜터가 현재 진행 상태를 확인하고 완료되지 않은 체크포인트부터 자동으로
배경 설명, Q&A, 설계 검증, 구현 과제, 테스트와 다음 단계 이관을 진행한다.

직접 참조할 문서를 지정하거나 이전 대화를 설명할 필요가 없다.

## 실행 전 요구사항

- Java 25
- Docker

환경 및 전체 테스트 확인:

```bash
./gradlew test
```
