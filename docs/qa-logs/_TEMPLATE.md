# {N}단계 Q&A 로그

이 문서는 AI 튜터가 각 질문의 답변을 판정한 **그 즉시, 같은 턴에** 기록한다
(`AGENTS.md` §5.2 참고). 아래 형식을 그대로 따르며 항목을 임의로 빼거나
이름을 바꾸지 않는다 — 세션이 달라져도 같은 문서 형태가 나오게 하기 위함이다.

이 로그는 통과 기준·후속 질문과 같은 비공개 판정용 정보다. 학습자에게 실시간
공개하지 않는다. 다만 base64 등으로 숨기지는 않는다 — 통과 기준/후속 질문
자체도 `STAGE_SPECS.md`에 평문으로 있으므로 같은 수준의 취급이면 충분하다
(§6의 "내부 판정에만 사용" 범주).

용도: (1) 즉석 후속 질문이 문서에 편입됐는지 추적, (2) 학습자가 어떤 유형의
개념에서 반복적으로 헷갈리는지 파악, (3) 추후 이 단계 Q&A를 재정리할 때
근거 자료로 사용.
